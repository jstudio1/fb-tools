# Facebook Multi-Page Poster

เว็บแอปเล็กๆ สำหรับโพสต์รูปภาพ + ข้อความเดียวกัน ไปหลายเพจ Facebook พร้อมกันในคลิกเดียว
มีตั้งเวลาโพสต์ล่วงหน้า (ผ่านระบบ scheduled post ของ Facebook เอง), แนบได้หลายรูปต่อโพสต์
และเก็บประวัติการโพสต์ย้อนหลัง

อยากให้ช่วยคิดแคปชั่น? เปิด [claude.ai](https://claude.ai) คุยขอแคปชั่นแยกต่างหาก แล้วก็อปข้อความมาวางในช่อง
"เนื้อหาโพสต์" ของแอปนี้ได้เลย (แอปนี้ไม่เรียก AI API ใดๆ เอง จึงไม่มีค่าใช้จ่ายเพิ่มเติม)

## ขั้นตอนติดตั้งครั้งแรก

### 1) ติดตั้ง dependencies

```bash
npm install
```

### 2) สร้าง Facebook App

1. ไปที่ [developers.facebook.com/apps](https://developers.facebook.com/apps) → สร้างแอปใหม่ → เลือกประเภท **Business**
2. ในแอป เพิ่มโปรดักต์ **Facebook Login** (ไม่ต้องตั้งค่าอะไรเพิ่มตอนนี้)
3. ไปที่ **Facebook Login > Settings** → ใส่ **Valid OAuth Redirect URIs** เป็น:
   ```
   http://localhost:3000/api/auth/callback
   ```
4. ไปที่ **Settings > Basic** → คัดลอก **App ID** และ **App Secret** ไว้ใช้ในขั้นตอนถัดไป
5. ไปที่ **App Roles > Roles** → เพิ่มบัญชี Facebook ของคุณ (และเพื่อนร่วมทีมที่จะใช้แอปนี้) เป็น **Administrator** หรือ **Developer**
   - ข้อนี้สำคัญ: ตราบใดที่แอปยังไม่ผ่าน App Review (**Development Mode**) มีแค่บัญชีที่อยู่ใน App Roles เท่านั้นที่ใช้แอปโพสต์ได้ ถ้าเป็นแค่คุณคนเดียวจัดการ 10 กว่าเพจ ไม่ต้องขอ App Review เลย ใช้ Dev Mode ได้ตลอด

### 3) ตั้งค่า environment variables

```bash
cp .env.local.example .env.local
```

แล้วเปิด `.env.local` ใส่ `FB_APP_ID`, `FB_APP_SECRET` ที่คัดลอกมา

### 4) รันแอป

```bash
npm run dev
```

เปิด http://localhost:3000

### 5) เชื่อมต่อเพจ Facebook

กดปุ่ม **"เชื่อมต่อ / ซิงก์เพจ Facebook"** → ล็อกอินและกด "อนุญาต" ที่หน้า facebook.com (ไม่ใช่หน้าเว็บนี้)
ระบบจะดึงรายชื่อทุกเพจที่คุณเป็นแอดมินมาเก็บไว้อัตโนมัติ (เก็บ token ไว้ในเครื่องที่ `data/pages.json` — **ไม่อัปโหลดขึ้น git**)

Token ที่ได้ปกติจะไม่หมดอายุเอง ตราบใดที่ไม่ไปกด revoke สิทธิ์แอปในบัญชี Facebook หรือหลุดจากแอดมินเพจ
ถ้ามีเพจใหม่เพิ่มมาทีหลัง กด "เชื่อมต่อ / ซิงก์เพจ Facebook" อีกครั้งเพื่อดึงรายชื่อล่าสุด

## การใช้งาน

1. แท็บ **"โพสต์ใหม่"** → ติ๊กเลือกเพจที่จะโพสต์ (มีปุ่มเลือกทั้งหมด)
2. (ถ้าต้องการ) กดลิงก์ "เปิด Claude.ai" คุยขอแคปชั่น แล้วก็อปมาวาง หรือพิมพ์เองในช่อง "เนื้อหาโพสต์"
3. แนบรูปได้หลายรูป (ลบทีละรูปได้)
4. เลือก **โพสต์ทันที** หรือติ๊ก **ตั้งเวลาโพสต์ล่วงหน้า** แล้วเลือกวันเวลา (ล่วงหน้าอย่างน้อย 10 นาที ไม่เกิน 75 วัน — Facebook จะโพสต์ให้เองตามเวลานั้น ไม่ต้องเปิดแอปทิ้งไว้)
5. กดโพสต์ → ดูผลลัพธ์รายเพจด้านล่าง (สำเร็จ/ไม่สำเร็จ พร้อมเหตุผล)
6. ดูย้อนหลังได้ที่แท็บ **"ประวัติการโพสต์"**

## ความปลอดภัยของข้อมูล

- `data/pages.json` เก็บ Page Access Token ของทุกเพจ — เป็นไฟล์ในเครื่องคุณเท่านั้น อย่า commit ขึ้น git หรือแชร์ให้ใคร (อยู่ใน `.gitignore` แล้ว)
- `.env.local` เก็บ App Secret ของ Facebook App — อย่า commit เช่นกัน (อยู่ใน `.gitignore` แล้ว)
- แอปนี้ออกแบบให้รันบนเครื่อง/เซิร์ฟเวอร์ของคุณเองเท่านั้น ถ้าจะ deploy ขึ้นที่สาธารณะ ควรเพิ่มระบบล็อกอินป้องกันคนนอกเข้าถึงหน้าเว็บก่อน

## Deploy ใช้งานจริง (ไม่ใช่แค่ localhost)

ถ้าอยากใช้งานได้จากทุกที่ (ไม่ใช่แค่เครื่องตัวเอง) ให้ deploy ขึ้น hosting ที่รองรับ Next.js (เช่น Vercel) แล้วอัปเดต:
- `FB_REDIRECT_URI` และ `APP_BASE_URL` ให้เป็นโดเมนจริง
- เพิ่มโดเมนจริงใน "Valid OAuth Redirect URIs" ของ Facebook App ด้วย
- เพิ่มระบบล็อกอินหน้าเว็บ (Basic Auth หรืออื่นๆ) กันคนนอกเข้าถึง เพราะข้อมูล token ของทุกเพจอยู่ในระบบนี้
